Instructions for Video

  1. Select Start Assignment.
  2. Select Insert. Select Media.
  3. Choose Record/Upload Media.                                                                                                                                                     
  4. If recording directly, the app will prompt you to allow access to your camera and microphone. Then select Start Recording.
  5. If you do not see the Insert option, look for the media icon (circled in red below). Select the media icon and select Upload/Record Media. On small screens, you might need to swipe left or right to access the media icon.
  6. If you are uploading a pre-recorded video, select the file from your device storage.
